# Settings

**Audience:** Someone running a game with Coffee Pub Scribe.

Every Scribe setting, by the name it carries in Foundry's Configure Settings window, under Module
Settings for Coffee Pub Scribe.

**All of these are world settings.** One person changes them and everyone at the table gets the
change; only a GM can reach them.

## Theme

**Card Style.** Which Blacksmith card theme Scribe's chat cards wear. The list is supplied by
Blacksmith, so it holds whatever themes your installed version offers. Leave it on Blacksmith Default
and Scribe follows the card colour set in Blacksmith's own settings, which keeps every Coffee Pub
card in the world looking alike.

If you have upgraded from a Scribe older than 13.1.0, this setting held a colour name that no longer
exists. Your cards use the world default until you pick from the new list.

Changing this affects cards posted from now on. Cards already in the chat log keep the colour they
were posted with.

## Journal Toolbar

**Toolbar Enabled.** Whether the toolbar appears on narration blocks at all. Turn it off and Scribe
adds nothing to journal pages. The journal title bar button is separate and stays.

**Show Button Labels.** Whether toolbar buttons show their name beside the icon, or the icon alone.
Turn it off for a narrower toolbar.

The next five decide which buttons are on the toolbar. Each needs Toolbar Enabled to be on. Turning
all five off removes the toolbar entirely rather than leaving an empty bar.

**Narration Button.** Posts the passage to chat as a card.

**Illustration Button.** Posts a single image from the passage to chat. One button appears per image
in the block, so a passage with three pictures gets three.

**Handout Button.** Copies the passage into a journal entry the players can open, and posts a link to
chat.

**Copy Button.** Puts the passage's HTML on your clipboard.

**Export Button.** Saves the current journal page as an HTML file, asking for a filename first.

**Print Button.** Despite the name, this controls the button in the journal window's title bar, which
opens the whole journal in a new browser tab for printing or saving as a PDF. Its on-screen name and
its tooltip disagree -- the tooltip reads Export Journal.

## Handouts

These two apply to the Handout Button.

**Folder.** The name of the folder new handouts are filed in. Party Handouts unless you change it.
Scribe creates the folder the first time it needs it. Change this and later handouts go to the new
folder; ones already created stay where they are.

**Folder Color.** The colour of that folder in the journal sidebar, as a hex value such as `#77274e`.
